Selected work & talks

Research in practice

  • Research highlight · WecNLP 2021

    Entity Transformer for multiple product name entities

    The work describes a sequence-to-sequence approach for recognizing up to 10 product items in an ordering utterance. The best reported model improved performance by 12% over the non-neural baseline on the reported test set. View the poster.

  • Voice search refinement

    Multi-facet actions for improved conversational item search refinement

    A multi-facet filter manager identifies facets and actions from a user's utterance, applies operations such as exact match, exclusion, greater-than, and less-than filtering, and ranks the remaining catalog items. Show patent.

  • Autonomous API agent

    Talk to APIs through an autonomous agent

    Patent application 18/999,673, filed December 23, 2024. The work focuses on an autonomous API agent for interacting with APIs through natural language.
